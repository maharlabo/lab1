## Калькулятор
Поддержиает следующее:
1. Операции с целыми и вещественными числами
2. Операции +, -, *, /
3. Соблюдение приоритета между *, / и +, -
4. Операции //, % (имеют равный приоритет с * и /)
5. Унарные + и -
6. Операции со скобками

При вводе выражения пробелы не учитываются, за исключением некоторых случаев (например, пробел между цифрами числа)
История успешных вычислений сохраняется в файл history.json

Как это работает
Результат получается в 3 этапа: Validation (validation.py), Tokenization (tokenization.py), Calculation (calculation.py)

1. Validation
Проверяет наличие следующих ошибок:
- пустое выражение
- недопустимый символ
- пропущенный операнд
- два бинарных оператора подряд
- деление на ноль
- неверное числовое значение
- пропущенные скобки
2. Tokenization
Рассмотрим на примере выражения "45+12*43-(65//11---3)"
Tokenization делится на три этапа
1) Строка превращается в список из чисел и операций и скобок. Результат: ['45', '+', '12', '*', '43', '-', '(', '65', '//', '11', '-', '3', ')']
2) Для соблюдения приоритетов расставляются дополнительные скобки. Результат: ['45', '+', '(', '12', '*', '43', ')', '-', '(', '65', '//', '11', '-', '3', ')']
3) Полученный список преобразуется в строку RPN - вида: "45 12 43 * + 65 11 // 3 - - "
Для учёта выражений скобках функция рекурсивно вызывается для каждого выражения внутри скобок
3. Calculation
Разделяет полученную строку с помощью split и выполняет операции: число - добавить число в стек, операция - выполнить операцию на последними двумя числами в стеке и записать результат в стек.

## Конвертер
Величины для конвертации можно задать в файле measures.json. В этом файле хранится несколько групп.
Общие поля для всех величин:
group - название группы
type - тип конвертации (обычный или формулой)
measures - определения величин (в зависимости от типа)
default_measure - величина по умолчанию (необязательно)
below_limit, above_limit - ограничения снизу и сверху соответственно для величины по умолчанию (в этом случае default_measure - обязательный параметр)

Типы конвертаций:
1. Default (обычный)
Величины задаются числом. Результат высчитывается с помощью пропорции
2. Formula (формулой)
Для этого типы поле default_measure - обязательно.
Величины задаются следующим образом: ["Формула преобразования из основной величины в данную", "Формула данной величины в основную"]
Преобразование выполняется в два этапа: Validation (validation.py), Convertation (convertation.py)
1. Validation
Проверка на существование величин в JSON-файле и принадлежность к одной группе
2. Convertation
Преобразование в зависимости от типа
